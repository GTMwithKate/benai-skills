# Bundled icons

33 [Lucide](https://lucide.dev) glyphs, ISC licensed, licence text in `LICENSE.txt`.

Every one has been re-stroked from Lucide's default 2px to the 1.5px that `references/design.md` requires, so they are ready to inline as they are.

They are bundled so the icon rule cannot break on a machine with no web access. Inline the SVG directly, set `stroke` to your ink token via `currentColor`, and size at 18 to 20px for card and section marks.

`youtube` is deliberately absent. Lucide dropped it, and brand marks belong with the vendor logos rather than the glyph set. Fetch a real mark instead.

Need a glyph that is not here? Take it from Lucide or Radix so the whole page stays one set, and re-stroke it to 1.5px.
