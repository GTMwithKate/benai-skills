# Icon Reference (Unicode Emoji)

Default icon system: one Unicode emoji per card, inline before the label, two spaces after the emoji for breathing room ("🧠  Reasoning engine"). If the user's design system defines an icon set in `foundations/iconography.md`, prefer that set and use this file only as the concept-to-icon thinking guide.

## How to use icons

- **Always include icons in the visual proposal** so the user confirms copy AND icons together. Format proposals as: `🔔 EVENT FIRES: schedule / API / webhook`.
- **Default to an icon** wherever the concept has a natural visual analog (trigger = 🔔, cloud = ☁️, clock = ⏰, team = 👥).
- **Skip icons** only when the user says no for a section.
- **One icon per card.** More than one clutters.

## Rendering notes

- Standard single-glyph emoji render reliably everywhere (⚡ 🔔 🧠 ☁️ ⚙️ 🔌).
- **Avoid compound emoji** (ZWJ sequences like 👨‍👩‍👧 or 🧑‍💻): they break in many canvas and diagram fonts, including Excalidraw's.
- **Avoid skin-tone variants**: they render inconsistently across platforms.
