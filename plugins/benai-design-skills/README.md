# benai-design-skills

Eight skills, one framework. Define your brand once — then every asset you make obeys it.

## The framework

Every skill in this plugin runs the same four steps (see `framework.md`):

1. **Design system as the foundation.** Every skill reads your brand from one `design-system/` folder.
2. **References for every use case.** No asset gets designed from zero context.
3. **/design to plan and edit.** Every build starts on a design canvas with 2-3 layout variations for you to pick from, and edits happen on the canvas too.
4. **Turn every use case into a skill.** Any repeatable design task becomes its own skill.

## The skills

| Skill | What it does |
|---|---|
| `design-system-creator` | Builds your complete design system, with a visual brand-teardown review before anything is written |
| `firecrawl-brand-extractor` | Extracts brand tokens straight from any website |
| `infographic-builder` | Infographic templates that adapt themselves to your brand |
| `carousel-builder` | Social carousels: hook, body, CTA — planned on a canvas, rendered from HTML templates |
| `visuals-builder` | Six reusable visual archetypes for diagrams, comparisons, and frameworks |
| `analytics-dashboard-builder` | Interviews you, connects your data, and builds a live dashboard with a daily refresh |
| `email-design` | Premium-looking emails that still survive Outlook, Gmail, and dark mode |
| `design-template-skill-creator` | Turns any design use case you repeat into its own skill |

## Where to start

No design system yet? Run `design-system-creator` first (or `firecrawl-brand-extractor` if your website already carries the brand). Every other skill builds on that output.
